## 本轮专项结论

### 临时插件箱

- 已新增通用说明窗口和每个 DLL 的功能说明/使用步骤清单。
- 说明读取优先级：`<DLL名>.microtool.json → microtool.json → microtool.package.json`。
- 功能说明或使用步骤不完整时禁止运行和收藏；可一键创建模板。
- 开发指南更新为内容版本 V3.1，并加入 Revit 版本、主线程、事务、依赖、性能和验收规范。

### 文本等距分布

- 逻辑本身不是按文字外框，而是按 `TextNote.Coord` 插入点移动。原说明容易让用户误以为是“可见边缘等距”。
- 已改成六个明确模式：垂直等距并对齐 X、水平等距并对齐 Y、垂直等距保留 X、水平等距保留 Y、仅对齐 X、仅对齐 Y。
- 排序后的第一个文本保持原位；拾取返回顺序在框选时不保证等于人工点选顺序，坐标排序更稳定。

### 文本基准对齐

- X 坐标相同表示插入点位于同一竖直线；Y 坐标相同表示位于同一水平线。
- 旋转围绕每个目标自己的插入点进行。它不保证文字可见边框对齐。
- 新增可选“段落宽度相同”：精确复制源 `TextNote.Width`，不复制内容、类型、字号或格式；允许只执行宽度同步。
- 源宽度必须位于目标文字类型的允许范围内；否则该目标回滚并记录原因，不做静默夹取。
- 每个目标使用独立 `SubTransaction`；锁定、成组、受约束或宽度不兼容的目标失败时跳过并统计，不再使全部目标失败。

### 中文检查

- 旧实现的 5000 族实例截断、共享参数遗漏、CJK 范围和危险“参数名命中即删除宿主”问题已经消除。
- 当前升级为“中文检查与清理”：39 个细分类别，左侧分类 + 右侧 DataGrid；支持搜索、复选、全选/全不选/反选、定位与复制 ID。
- 双击“名称 / 内容”只对明确支持写入的对象开放：元素名、TextNote、字符串参数、工作集、图号、明细表列标题、空间编号、装配类型名等。
- 实体删除先在回滚事务中执行 `Document.Delete` 级联影响预检，高风险二次确认；字符串参数的删除语义是清空值，不删除宿主。
- 批量清理一个主 Transaction + 每项 SubTransaction，单项失败隔离，成功批次一次 Ctrl+Z。
- 仍不扫描 Revit 链接文档内部、族文件内部，也不使用 `AsValueString()` 扫数值本地化显示。

### 系统设置 / 面板设置

- 原实现关闭窗口时自动保存，用户无法取消；也允许把一个面板全部移入展开区，可能造成入口不可访问。
- 现在关闭不保存；只有显式点击保存才写入。系统设置固定显示，每个面板至少保留一个主区按钮。
- 支持当前面板全选、当前面板恢复默认、全部面板恢复默认。
- 配置按完整快照写入，清理过期命令键；使用 `.tmp` 写入和 `.bak` 备份。
- 主题切换仍是即时应用并即时保存；面板布局则明确保存后、重启 Revit 生效。

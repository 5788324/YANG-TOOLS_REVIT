# YangTools 3.1.35 检查报告复核与定点修复

日期：2026-08-05  
复核对象：`REVIEW_批处理与云链接_2026-08-03.md`、用户提供的项目资产管理器截图、`Source_FIX_20260730` 源码。

## 结论

原检查报告发现了多项真实缺陷，但把若干“防御性不足、设计限制或待实机验证项”直接写成确定性高危 Bug，也包含几项与 Revit API 约束或当前入口代码不符的结论。本轮按源码事实重新分级：

- **已确认并修复**：项目资产管理器表头列宽、管理器参数绑定、过滤状态、事务回滚、世界坐标放置、图纸窗口初始化、Revit 2021 PDF 入口等。
- **保留为实机待证**：ACC/Autodesk Docs 链接路径的重复识别、布尔失败几何、快速切换时序、批量导出旧文件保护等。
- **从明确 Bug 中移除**：族类别修改时给项目文档额外开启事务、族文档列头 ComboBox 必然无限循环、项目资产管理器正常 Ribbon 入口无文档必然 NRE、Revit 允许同一图纸集重复图号等。

当前源码静态层面可进入 Windows 编译；正式发布仍为 NO-GO。

## 一、用户截图：项目资产管理器“视图过滤”列宽

### 根因

表格原有固定列约 300 px，右侧两个参数列的列头 ComboBox 各约 120 px，再加新增列按钮；三个过滤状态列使用 `Star` 自动分配。窗口剩余宽度不足时，三个状态列被压缩到仅能显示单个字符。

### 修复

`ProjectAssetManagerWindow.xaml.cs`：

- 是否控制实例元素：`Width=120`，`MinWidth=110`；
- 是否在视图中使用：`Width=120`，`MinWidth=110`；
- 在视图样板中是否使用：`Width=150`，`MinWidth=135`；
- 动态参数列：`Width=140`，`MinWidth=130`；
- 列头 ComboBox：`Width=125`；
- 新增列按钮列：`Width=44`，`MinWidth=40`。

窗口不足时允许横向滚动，不再牺牲过滤状态列的可读性。

### 2.3 族实例管理

- 参数绑定路径长度确实少算 1 个字符，已从 `Length - 19` 修正为 `Length - 18`。
- “选择图元”过滤现在记录所属族；切换其它族自动解除。
- 首个选择不是可管理载入族时，明确提示并清除过滤，不再沿用旧族状态。
- Tab 切换会重新载入对应配置、数据和动态列，避免两页共享字段造成显示串页。

### 2.4 族文档管理

- 参数绑定路径同样修正为 `Length - 18`。
- 原报告的“列头 ComboBox 必然无限循环”不成立：当前源码是在设置 `SelectedValue` 后才挂接 `SelectionChanged`。本轮仍增加“选择值未变化则立即返回”的防重入保护。
- 原报告要求 `familyDoc.LoadFamily(projectDoc, ...)` 外包项目 Transaction，结论错误。该 API 要求目标项目文档不能处于可修改状态；本轮保留无项目事务调用，增加返回值检查和说明注释。
- ExternalEvent 重入、编辑失败后的视觉回滚仍需 Windows/Revit 交互验证。

### 2.5 项目资产管理器

已修复：

- 导出表头 `图元 ID/名称` 与导入表头兼容，同时保留 `图元ID/元素ID/资产名称` 旧格式兼容；
- 导入成功数只统计真实发生修改的行；
- Project Info 行使用参数 ID，不再允许“视图中选择、删除、批量重命名”；
- FilledRegions/LineStyles 只显示一个操作栏，避免遮挡；
- `AnalyzeFilterBtn` 每次切页先复位，避免可见性泄漏；
- 动态参数绑定名截断问题修正为 `Length - 18`；
- 填充图案/线型不再在 `SelectionChanged` 时立即写库：下拉关闭后才提交；下拉关闭状态下滚轮不会改变选择；
- `DuplicateFilledRegion` 的异常路径显式回滚；
- 用户截图中的过滤状态列改为固定最小宽度。

报告中的“无活动文档时窗口必然 NRE”不适用于正常 Ribbon 入口：`ProjectAssetManagerCommand` 已在创建窗口前检查 `ActiveUIDocument`。构造函数本身仍依赖有效文档，这是入口契约，不单列运行时 Bug。

### 2.6 图纸管理

已修复：

- 增加 `_isInitialized` 和读事件对象守卫，避免 `InitializeComponent` 期间 Tab 事件访问未初始化处理器；
- 图框表第二列列头从重复的“所属图纸”改为“图名”；
- 图框状态栏默认文字改为“共计 0 个图框实例”。

原报告关于“Revit 允许重复图号，因此 `ToDictionary` 会在合法项目上失败”的论据不成立。Revit 的图纸编号在完整图纸集中要求唯一；如果未来需要支持新版 Sheet Collection 的分组语义，应基于对应 API 和真实模型另行设计，不能把当前代码直接判为高危 Bug。

## 本轮新增修复

1. **Desktop Connector / Autodesk Docs 重复链接识别**
   - 新增 `ExternalLinkPathMatcher`。
   - 本地路径与 `Autodesk Docs://` 显示路径先做 URL 解码、分隔符和基础设施目录归一化。
   - 必须同时匹配文件名和至少两级父目录，避免只按文件名误判。
   - 该规则是安全的尽力匹配，仍需真实 ACC/Desktop Connector 项目验证。

2. **合并 PDF 覆盖保护**
   - 目标已存在且勾选覆盖时，先导出到唯一临时文件。
   - 导出成功后才把旧文件移到备份并替换。
   - 替换失败时自动恢复旧文件；恢复也失败时保留临时文件与备份路径供人工取回。
   - 导出失败不再先删除旧 PDF。

3. **布尔融合失败重叠保护**
   - Union 失败后检查两实体交集。
   - 存在正体积交集或交集关系无法安全判断时，整次操作报错回滚，不再输出可能重叠的实体。
   - 明确无有效交集时才保留为独立实体。

4. **Excel 批量导入原子化**
   - 族实例、族类型、项目资产、图纸导入均使用 `TransactionGroup + 每行 Transaction`。
   - 单行失败只回滚该行，已成功行继续处理；最终合并为一个 Revit 撤销步骤。
   - 显示成功、跳过/失败数量及主要失败原因，不再仅写 `Debug.WriteLine`。
   - 图纸导入不再对图号直接 `ToDictionary`；项目中同图号对应多个目标时明确跳过并报告歧义。

5. **删除与图框换型保护**
   - 族实例、项目资产、图纸的普通删除也必须确认，不再只在发现级联删除时确认。
   - 删除预检、真实删除和事务组合并检查返回状态。
   - 图框快速连续换型增加实例级待处理守卫，上一请求完成前拒绝第二次写入并恢复显示。

## 明确保留的设计决策

- 多文档批处理找不到同名视图、视图集或导出设置时明确失败，不自动回退到当前视图。
- `familyDoc.LoadFamily(projectDoc, ...)` 调用时不额外开启项目文档事务。
- 不把所有 `Debug.WriteLine`、按钮 `IsEnabled` 和窗口可缩放一次性重构为本轮发布阻塞项。
- ACC 路径匹配不能只依赖文件名；若真实项目仍不能识别，必须根据 Revit 返回的实际路径样本定点调整。

# YangTools Ribbon 图标设计规范

版本：1.1  
适用范围：YangTools Revit Ribbon、菜单入口及后续新增功能图标。

## 1. 设计目标

YangTools 图标统一采用**简约、克制、优雅的工程线条风**。目标是在 Revit Ribbon 的 16×16 与 32×32 小尺寸下保持清晰，同时让不同功能看起来属于同一套产品。

核心原则：

- 只表达一个主要动作，不堆叠过多语义。
- 优先使用几何线条、轮廓、节点和方向关系。
- 不使用拟物材质、阴影、渐变、发光、照片或 Emoji。
- 不在图标中放中文、英文缩写或数字文字。
- 同类功能保持相同视觉语法，例如“复制”统一使用重叠轮廓，“修改”统一使用斜向编辑笔。

## 2. 画布与导出

| 项目 | 规范 |
|---|---|
| 主设计画布 | `32 × 32`，SVG ViewBox `0 0 32 32` |
| Ribbon 大图标 | `32 × 32 PNG`，透明背景 |
| Ribbon 小图标 | `16 × 16 PNG`，透明背景 |
| 色彩空间 | sRGB |
| 文件命名 | `<功能语义>_32.png`、`<功能语义>_16.png` |
| 源图生成 | `tools/Generate-RibbonIcons.py` |

16×16 图标必须由同一 SVG 母版重新栅格化，禁止简单缩小旧 PNG 后再手工涂改。

## 3. 线条系统

- 32×32 母版主线宽：`1.85`。
- 线帽：`round`。
- 线连接：`round`。
- 主轮廓色：`#355D7A`，深蓝灰。
- 辅助强调色：`#6E9FC4`，仅用于关键动作、路径或状态。
- 每个图标强调色面积不宜超过整体视觉信息的约 30%。
- 默认不填充大面积色块；节点允许使用小面积实心圆点。

## 4. 几何与留白

- 主要图形控制在 `4–28` 的安全区域内。
- 最外侧至少保留约 `3 px` 视觉留白。
- 直线尽量落在整数或半像素坐标，减少栅格化发虚。
- 圆角半径通常使用 `1–2`。
- 小节点直径通常为 `2–3`。
- 图标重心应位于画布中心，避免明显偏左、偏上或底部过重。

## 5. 功能语义规则

### 文本工具

- 使用短横线或简化的 `T` 形轮廓表示文本。
- 对齐：增加基准线。
- 分布：增加等距箭头或均匀节点。
- 合并：多组线条汇聚为一组。
- 修改：文本轮廓配合斜向编辑笔。

### 模型修改

- 路径：使用一条连续强调色曲线。
- 布置：在路径上放置等间距节点或构件。
- 几何：使用轮廓、叠加、剖切或体块关系。
- 创建与提取必须使用不同动作语义：创建强调轮廓生成体量，提取强调从源实体向外输出对象。
- 标高：使用平行水平线与竖向箭头。

### 项目管理

- 文档：矩形纸张轮廓与折角。
- 族：立方体、体块或模块网格。
- 图纸：叠放的页面轮廓。
- 检查：放大镜、信息节点或勾选标记。
- 重复参数清理：使用叠放参数记录表达重复，以收敛线/勾选表达保留并清理。

### 系统与 AI

- 设置：简化齿轮，不添加多余装饰。
- AI：对话气泡配合少量节点或闪光语义。
- 临时工具：工具箱或模块容器。

## 6. 禁止项

后续图标不得出现：

- 与现有图标不同的高饱和随机颜色。
- 3D 透视渲染、阴影、玻璃质感或渐变。
- 过细的发丝线，导致 16×16 下消失。
- 超过两种主色。
- 依赖文字才能理解的设计。
- 从网络随意下载、版权不明或风格不一致的图标。
- 仅为占位而复制其他功能图标；共享图标必须是语义确实一致。

## 7. 新增图标流程

1. 先确定功能的单一核心动作。
2. 在 `tools/Generate-RibbonIcons.py` 中新增母版绘制函数。
3. 使用本规范的颜色、线宽、圆角和留白。
4. 同时生成 16×16 和 32×32 PNG。
5. 更新命令的 `RibbonButton` 图标路径。
6. 运行 `Verify-SourceBaseline.cmd`，确认：
   - 所有 Ribbon 图标均存在；
   - 没有未引用 PNG；
   - 每个图标都有 16/32 两种尺寸；
   - PNG 尺寸和透明通道正确。
7. 在 Revit 浅色 Ribbon 中实际检查辨识度。

## 8. 当前资产原则

`src/YangTools.Revit/Icons` 只保留运行时实际引用的 PNG。SVG 中间文件、旧版图标、废弃功能图标和未引用资源不进入正式安装目录。

## 9. 功能级唯一性与文案同步（必遵守）

每个正式 Ribbon 功能必须使用独立、有区别的 16/32 图标族（而非文件改名复制），并同时维护 `RibbonButton` 中短名称、`tooltip` 与 `usage`。详细开发硬门禁见 `RIBBON_FEATURE_DEVELOPMENT_RULES.md`；交付前运行 `tools/Test-RibbonUxContract.py`。

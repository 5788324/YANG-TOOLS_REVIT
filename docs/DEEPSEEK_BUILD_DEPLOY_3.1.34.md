# DeepSeek 编译部署任务：YangTools 3.1.35

## 任务目标

编译、部署并实机验收 YangTools 3.1.35 的“重复项目参数清理”快速值索引引擎。不要再用 MCP/Python 脚本代替插件功能，必须通过 YangTools Ribbon 和 WPF 窗口完成全链路。

## 输入

源码包：`YangTools_Project_3.1.35_Source_CLEAN.zip`

目标环境：Revit 2021，使用已处理项目的备份副本或同结构测试模型。

## 编译部署

关闭 Revit 后执行：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\tools\Verify-SourceBaseline.ps1
.\tools\Build-All.ps1 -Versions 2021 -Deploy
```

要求：

- Release/x64/net48；
- 0 errors；
- warnings 如存在必须逐条报告；
- 不修改业务逻辑规避编译错误；
- 禁止把 Revit API 操作放入 `Task.Run`。

## 实机验收

入口：

```text
YangTools → 检查工具区 → 重复项目参数清理
```

### A. UI 与进度

1. 打开窗口。
2. 扫描重复参数。
3. 运行期间确认日志至少每 5000 个元素刷新一次，窗口不是几十秒完全无反馈。
4. 确认运行期间按钮禁用，完成后恢复。

### B. 10 个来源参数试运行

1. 点击“全不选”。
2. 点击“测试：最多 10 个来源参数”。
3. 快速处理。
4. 验证：
   - 值引擎为“快速值索引”；
   - 参数值完整性通过；
   - 完整清理组唯一性通过；
   - 没有身份熔断；
   - 可以 Revit 撤销。

### C. 全量试运行

只在 B 通过后执行。优先使用已被 `bulk_v3.py` 成功处理过的模型副本，以便对比。

记录：

- 项目参数总数、重复组、来源参数数；
- 快照/值索引耗时；
- 绑定合并耗时；
- 值迁移耗时；
- 复制、相同、冲突、错误数；
- 删除耗时与删除数；
- 最终剩余重复组；
- 参数值完整性；
- 全链路总耗时。

若测试 RIS_003 同类模型，重点确认约 21891 个需迁移值可以由插件完成，且错误不再出现数万条。

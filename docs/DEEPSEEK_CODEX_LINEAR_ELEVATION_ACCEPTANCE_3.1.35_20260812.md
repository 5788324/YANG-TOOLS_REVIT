## 原则

- 以 `YangTools_Project_3.1.35_Source_LINEAR_ELEVATION_20260812.zip` 为唯一源码基线。
- 不新增功能，不推送 Git。

- 用户不参与手工测试；能通过 Revit/MCP/GUI 自动化完成的全部由执行 AI 完成。

## A. 基线与编译

1. 解压到全新空目录。
2. 运行 `tools/Verify-SourceBaseline.ps1`、`Test-UiPanelsStatic.py`、`Test-LinearElevationProfile.py` 及现有全部专项。
3. 按本机可用 SDK 构建 2021–2027 独立 Configuration；禁止跨年份复用 DLL。
4. 至少部署 Revit 2024、2025；记录构建 DLL 与部署 DLL SHA-256。
5. 若 2027 缺 .NET 10 SDK，记录真实 NETSDK1045，不得写 PASS。

## B. Revit 高程专项（优先 2024，其次 2025）

准备一个 OneLevelBased / 可点式放置的轮廓测试族和一条至少 10m 连续路线。不得使用 TwoLevelsBased 结构柱作为本功能通过样本。

对每组记录：基准标高实际 Elevation、起点/终点输入、实例数、每个实例 LocationPoint.Z、LevelId、理论 Z、最大误差、撤销结果。

### B1 非零正标高

- 基准标高约 +12000 mm。
- 起点高程 0 mm，终点高程 +3000 mm。
- 固定数量 5。
- 期望相对高程：0 / 750 / 1500 / 2250 / 3000 mm。
- 期望世界 Z：约 12000 / 12750 / 13500 / 14250 / 15000 mm。

### B2 非零标高 + 负偏移

- 基准标高约 +12000 mm。
- 起点 -500 mm，终点 +2500 mm。
- 验证首点世界 Z = Level + (-500)，末点 = Level + 2500。

### B3 负标高

- 基准标高约 -3500 mm。
- 起点 0，终点 +2000。
- 验证世界 Z 分别从约 -3500 到 -1500 mm。

### B4 降坡

- 任一非零标高。
- 起点 +2000，终点 -1000。
- 验证中间值严格线性下降。

### B5 固定间距、末端不补实例

- 选择长度不能被间距整除的路线。
- 不勾选“末尾不足一个间距时补放终点实例”。
- 验证**实际第一个实例**=起点高程、**实际最后一个实例**=终点高程，中间按实际首尾距离插值。

### B6 反转路线

- 与 B1 同样输入，勾选“反转路线首尾”。
- 验证原路线末端成为新的首实例并取得起点高程；原路线起端成为尾实例并取得终点高程。

### B7 单实例

- 固定数量=1，起点/终点高程不同。
- 应出现明确提示；唯一实例使用起点高程；无事务残留。

### B8 方向

- `KeepVertical=true`：实例保持垂直，但 XY 朝向仍按路线切线。
- `KeepVertical=false`：使用新的首尾高程坡度进行俯仰，而不是旧路线原 Z 坡度。

### B9 撤销

每个正式写入案例完成后验证一次 Ctrl+Z 可撤销整个批次，实例数量回到执行前。

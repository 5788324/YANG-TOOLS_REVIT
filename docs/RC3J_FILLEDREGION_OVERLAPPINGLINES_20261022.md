# RC3J — 两个图形整理工具与 RC3I F1 编译修复

日期：2026-10-22；基线：RC3I，禁止影响 Revit 2023 生产宿主。

## F1 编译缺陷
- `TextLayoutMerger.TryColumns`: `cut` 是 `out` 参数，C# 禁止在 LINQ lambda 捕获；先复制到 `double cutValue` 并使用它。原始 F1 2021–2026 六版均 BUILD_FAIL。本版本尚未 Windows 重编译。

## 1. 填充隐形边界
- 仅选中的当前视图 FilledRegion。排除锁定、组内元素。对有效线型列表按 `<Invisible lines>` 唯一名称查找；无效或多义不修改。
- 使用 `FilledRegion.SetLineStyleId` 修改全部边界，不重新建 FilledRegion，不改填充类型/图案。预览、一次事务/Undo；错误回滚。
- 其他语系/项目线型名称不完全匹配会拒绝；需要实机验证。用户要求全部边界，而非部分边。

## 2. 清理重叠线段
- 仅选中的同一视图直线 DetailCurve，排除弧线、模型线、组、Pinned。仅同线样式，空间共线误差 <=0.1 mm、角度误差 <=1e-7，且共线投影存在**正长度重叠**才处理。
- 先聚合同覆盖区间，合并为相同覆盖范围的单段长直线。仅端点连接、纯交叉、不同线型、空间错开者原样保留；不扩大对象选择；最多1500选中元素。
- 会删除原线并新建线，旧 ElementId、标注引用可能失效，预览明确警告；单事务可Ctrl+Z。
- **不做拓扑意义的自动切断**，对于不同颜色、重合但不同线型的线不删除。与“合并直线”功能的端点连通判定不同。

## 实机测试（DeepSeek）
- 先 2021–2026 隔离 BUILD，提交6份日志与实际 DLL；2027缺.NET10 SDK记ENV_BLOCKED。
- F2仅独立无生产数据测试RVT，实际 GetElement/数量/边界样式读取与一次 Undo；涉及删除旧线引用必须验证；任何Revit生产实例不操作/不安装。
- 覆盖：两个同线完全重复、长线包含短线、部分重叠、反向重叠；共线仅端点相接不操作；不同线型不操作；交叉不操作；0.2mm偏移不操作；弧/模型线/锁定/组内不操作；6种填充图案；样式不在有效列表时不操作。
- 仅源码静态候选：静态GO != Windows BUILD GO != Runtime GO != Release GO。

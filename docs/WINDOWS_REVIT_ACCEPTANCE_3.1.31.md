# YangTools 3.1.31 Windows / Revit 验收单

## A. 编译部署

- [ ] 使用全新 3.1.31 目录。
- [ ] `tools/Verify-SourceBaseline.ps1` 通过。
- [ ] Revit 2021 `Release|x64/net48` 编译 0 error。
- [ ] 部署后功能区存在：`YangTools → 检查工具区 → 重复项目参数清理`。

## B. 选择工具

扫描后确认：

- [ ] `全选可处理项` 选中全部兼容组。
- [ ] `全不选` 清空全部选中。
- [ ] `反选` 正确反转兼容组。
- [ ] `测试：最多 10 个来源参数` 后右侧显示来源参数数 ≤ 10。
- [ ] 手工勾选行后选择统计更新。

## C. 10 个来源参数全链路

使用项目副本：

1. [ ] 扫描成功。
2. [ ] 点击 `测试：最多 10 个来源参数`。
3. [ ] 记录选中组数和来源参数数。
4. [ ] 点击 `快速处理：合并并清理`。
5. [ ] 绑定合并完成。
6. [ ] 参数值按内部类型复制完成。
7. [ ] 删除完成或明确显示受保护原因。
8. [ ] 自动重新扫描完成。
9. [ ] `07_清理后复核.csv` 已生成。
10. [ ] Revit 撤销后恢复。

## E. 全量测试

仅在 C 通过后执行：

- [ ] 全选可处理项。
- [ ] 记录绑定、值复制、删除、复核四阶段耗时。
- [ ] Revit 没有永久无响应或崩溃。
- [ ] 报告可打开。
- [ ] 撤销项为一个完整快速处理项。

## GO 条件

- 10 个来源参数完整链路通过；
- 自动复核与撤销通过；
- 无误删级联对象；
- 批量删除调用显著少于候选参数数；
- 全量操作耗时可接受。

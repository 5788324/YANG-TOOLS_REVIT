# YangTools 3.1.30 Windows / Revit 验收单

## 1. 编译

在全新源码目录执行：

```powershell
.\tools\Build-All.ps1 -Versions 2021
```

最低要求：

- 0 errors。
- 检查新增参数清理文件没有 Revit API 版本错误。
- 若出现 nullable warning，应完整记录；不得通过关闭 Nullable 掩盖。

随后可继续编译：

```powershell
.\tools\Build-All.ps1 -Versions 2024,2025
```

## 2. 部署

```powershell
.\tools\Build-All.ps1 -Versions 2021 -Deploy
```

部署脚本应自动移除旧独立插件；仍需确认以下路径不存在，避免出现两个入口：

```text
%APPDATA%\Autodesk\Revit\Addins\2021\RevitParameterDeduplicator.addin
%APPDATA%\Autodesk\Revit\Addins\2021\RevitParameterDeduplicator\
```

正式入口只应来自 YangTools。

## 3. Ribbon 与主题

检查：

```text
YangTools → 检查工具区 → 重复项目参数清理
```

- 按钮文字正确。
- 新图标清晰，不与中文检查图标混淆。
- 窗口跟随当前 YangTools 主题。
- 切换四套主题后重新打开窗口，无白底、黑字丢失或 StaticResource 异常。
- “功能说明”位于“关闭”旁边，内容可正常打开。

## 4. 扫描

使用用户项目副本：

- 项目参数约 2750。
- 重复组约 606。
- 构件 2000+。

记录：

```text
扫描耗时：
项目参数总数：
唯一名称：
不重复参数：
重复组：
可处理组：
```

运行输出必须出现“扫描预览报告”，并包含：

- 理论清理后项目参数数量。
- 理论剩余重复组。
- 理论不重复参数数量。
- 保守可删除预估。
- 已知至少剩余重复组、预计最多形成的不重复参数。
- 最终结果需执行后重新扫描的说明。

## 5. 快速处理

先保存 RVT 副本，然后点击：

```text
快速处理：合并并清理
```

记录四阶段耗时：

```text
绑定合并：
实例元素单次遍历：
类型元素单次遍历：
删除：
总耗时：
```

日志应显示：

- 多少组无需 ReInsert。
- 实际 ReInsert 多少组。
- 实例和类型分别检查多少元素。
- 复制值、冲突、错误数量。
- 删除成功、级联回滚和保护数量。

## 6. 清理后自动复核

快速处理完成后无需手动点扫描，程序应自动重新扫描并输出“清理后复核报告”：

```text
项目参数：清理前 → 清理后
重复组：清理前 → 清理后
不重复参数：清理前 → 清理后
清理后仍有重复参数：是/否
```

报告目录应包含：

```text
00_汇总.csv
01_重复参数组.csv
02_参数明细.csv
03_引用关系.csv
04_参数值冲突.csv
05_错误.csv
06_删除记录.csv
07_清理后复核.csv
```

## 7. 值验证

至少抽查四类参数：

- Double（长度/面积等）。
- Integer/YesNo。
- String。
- ElementId（材质/类型类引用，若项目存在）。

确认清理前后内部值一致。不得只比对界面显示文本。

## 8. 级联删除保护

选择一个被明细表或过滤器引用、或删除时会产生额外对象的来源参数：

- 该来源参数应被保护或回滚。
- 其他参数继续处理。
- CSV 写明额外 ElementId/对象名称。

## 9. 撤销

快速处理完成后执行一次 Revit Undo：

```text
重复项目参数：合并并清理
```

重新扫描，参数数量和重复组应恢复到处理前。

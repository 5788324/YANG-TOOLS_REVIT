## B. Revit 2024 强制 GUI 与功能验收

### B1. 项目资产管理器

1. 打开“视图过滤”页，截取完整窗口：
   - 三个状态列标题必须完整可读；
   - 宽度分别约为 120/120/150；
   - 窗口较窄时出现横向滚动，不得把状态列压成单字；
   - 动态参数列的 ComboBox 不得遮挡“+”。
2. 导出当前页 Excel，再用同一文件导入：
   - 能识别 `图元 ID` 和 `名称`；
   - 未修改行不计入成功数；
   - 修改名称/可写参数后能写回并可撤销。
3. Project Info 页：
   - “视图中选择、删除、批量重命名”应提示不适用，不能抛异常；
   - 参数值编辑保持可用。
4. FilledRegions/LineStyles：
   - 底部操作栏不重叠；
   - 过滤分析按钮不残留；
   - 下拉关闭时滚轮不应改选项；打开下拉选择并关闭后只执行一次写入；Ctrl+Z 可撤销。

### B2. 族实例管理

1. 族实例页和系统实例页各编辑一个可写参数，确认参数名没有截断并真实写入。
2. 使用“选择图元”过滤，再切换其它族：旧过滤应自动解除。
3. 选择非 FamilyInstance：显示中文提示，不得保留旧族过滤。
4. 在两个 Tab 之间反复切换，动态列配置不得串页或空白。

### B3. 族文档管理

1. 反复切换动态参数列，确认没有递归刷新或冻结。
2. 修改一个可编辑族类别：
   - 族文档事务提交；
   - 项目文档在 `LoadFamily` 时不得处于可修改状态；
   - 修改后的族成功重载；
   - 失败时 UI 与模型状态一致。
3. 保存 Journal 和异常日志。

### B4. 图纸管理

1. 从 Ribbon 打开窗口并快速切换两个 Tab 10 次，不得 NRE、重复加载或黑屏。
2. 图框列表列头必须为“所属图纸 / 图名”，状态栏为“图框实例”。
3. 对导入、删除、换型各做最小成功和失败案例；记录 UI 反馈和撤销结果。

### B5. 线性布置

1. 在平面视图和 3D 视图分别测试水平线、带 Z 高差斜线。
2. 标高型点族必须放在曲线真实世界 Z，误差不超过 1 mm。
3. 3D 视图无 `GenLevel` 时应选择最近标高并成功放置。
4. 选择两组断开曲线，必须提示忽略数量，不能静默缩短总路线。
5. 制造一个旋转或放置失败案例：整次事务回滚，`doc.IsModifiable=false`，后续命令仍可执行。
6. 成功操作一次 Ctrl+Z 全部撤销。

### B6. 基于面转换

1. 正常转换至少 2 个实例，比较转换前后世界坐标和旋转。
2. 原实例位于非零偏移/负标高时，新实例中心坐标误差不超过 1 mm。
3. 人为提供失败模板或不可载入族：
   - 当前实例子事务回滚；
   - 旧实例保留；
   - 不留下半成品新实例；
   - 文档不保持可修改状态。
4. 验证删除旧实例选项和 Ctrl+Z。

### B7. 标高修改

1. 对一个需要重建的点族修改标高，世界位置保持不变。
2. 人为制造参数复制或删除失败：不能同时留下新旧两份实例。
3. 成功操作可一次撤销。

### B8. 布尔几何

1. 正常融合/剪切各一例。
2. 制造不可布尔实体或 FreeFormElement 创建失败：
   - 族文档事务回滚；
   - 族文档可以正常关闭；
   - 项目事务组回滚；
   - 原族和目标实例不丢失。
3. 对失败融合的实体截图并判断是否有重叠输出；没有证据不得改算法。

### B9. 批处理与云链接

1. Revit 2021：PDF 复选框必须禁用，不能进入执行时报错。
2. Revit 2024：NWC/IFC/DWG/PDF 做最小导出；缺少同名视图/设置时应显示明确错误。
3. 链接创建失败或 Commit/Assimilate 非 Committed 时，记录状态；后续链接仍可启动，文档可关闭。
4. 使用真实 ACC/Autodesk Docs + Desktop Connector 文件重复运行两次：
   - 勾选“跳过已存在”；
   - 记录候选本地路径、Existing ExternalFileReference 可见路径、是否重复创建；
   - 只有得到日志后才允许修改云路径等价算法。
5. PDF 覆盖测试：保留一个旧 PDF，制造导出失败，确认旧文件是否丢失；若丢失，再实施备份—成功替换—失败恢复的定点修复。

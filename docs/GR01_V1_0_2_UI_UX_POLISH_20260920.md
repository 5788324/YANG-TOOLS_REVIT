# GR01 V1.0.2 UI/UX Polish

日期：2026-09-20

## 目标

本轮仅修复/优化已验收 GR01 V1.0.1 的 WPF 交互，不修改 spacing planner、几何插值、CreateFreeForm、事务、readback、Undo、MCP 业务算法。

## 1. 鼠标滚轮修复

问题根因是外层 `ScrollViewer` 与 `ZoneGrid(DataGrid)` 内部 `ScrollViewer` 嵌套。鼠标位于 DataGrid 上时，滚轮被内部 ScrollViewer 消费；当表格本身无可滚内容或已到顶/底时，事件不会自然推动外层窗口。

V1.0.2：
- 外层命名为 `MainScrollViewer`；
- `ZoneGrid.PreviewMouseWheel` 检查 DataGrid 内部 ScrollViewer；
- DataGrid 仍可滚时保留其自身滚动；
- DataGrid 到顶/底或本身不可滚时，将滚轮交给外层 `MainScrollViewer`。

因此不会通过禁用 DataGrid 滚动来“修复”窗口滚动。

## 2. ModelLine / Edge 方向语义统一

产品业务方向统一为：

`Start Control -> End Control`

ModelLine / Edge 只提供：
- 分布轴线；
- 可用有限范围；
- 基准几何总长。

它们自己的 Revit Endpoint0/Endpoint1 方向不作为用户业务方向。Core 内部仍保留 `PathReversed` 用于投影归一化，但 GUI 不再把它显示成第二套“正/反方向”。

`Zone[0]` 永远从起始控制筋一侧开始。需要反向时使用现有 `交换首末`。

## 3. 基准总长与有效长度分离

对 ModelLine / Edge：
- 拾取后显示 `基准总长`；
- Preview 后显示两根控制筋投影之间的 `有效长度`；
- 不再把整条 ModelLine/Edge 长度误称为分布长度。

ZAxis：
- 基准为全局 Z；
- 无需拾取；
- Preview 后显示 Start/End 控制筋的 Z 向有效长度。

## 4. Auto Remaining 行可读性

- `自动剩余` CheckBox 改为 `长度模式` 单元格，显示 `固定 / 自动剩余`；
- 自动区长度未解析时显示 `待计算`，不再显示误导性的 `0`；
- 自动区长度编辑框禁用；
- 表头补全 `mm` 单位。

## 5. 输入即时校验

GUI 在 Preview 前直接检查：
- 固定长度 > 0；
- 最大间距 > 0；
- 手动实际间距 >0 且 <= 最大间距；
- 最多一个自动剩余区；
- 已知有效长度时，固定区不得超配；
- 无自动区且已知有效长度时，固定区合计必须匹配有效长度。

错误信息显示在 Zone 表下方，同时 Preview 按钮禁用，并通过 ToolTip 提示缺少的输入。

## 6. 其他小改进

- 新增区段插入到当前选中行之后；
- 标题副标题移除 `GR01 V1 / Revit 2025` 等开发阶段字样；
- 保留底部技术披露 `Managed FreeForm (ManagedGeometry) / not Native ToCover`；
- `分布路径` 文案调整为 `分布基准`，避免误导为路径自身决定业务方向。

- spacing algorithm 不改；
- Line/Arc interpolation 不改；
- PlanFingerprint 不改；
- CreateFreeForm 不改；
- Transaction / rollback / Undo 不改；
- V1.1 Update 不进入本轮；

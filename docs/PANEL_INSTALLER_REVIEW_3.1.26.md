# YangTools 3.1.26 项目分析、面板检查与安装器评审

日期：2026-07-21

## 结论

- **源码静态结论：GO。** XAML、资源、事件处理器、主题隔离和 UTF-8 未发现阻止窗口构造的静态错误。
- **Windows 编译结论：未执行。** 当前审查环境没有 Windows/.NET SDK/Revit，不能把静态通过写成编译通过。
- **Revit 面板实机结论：待验收。** 需要在 Revit 2024 中逐个点击入口后才能确认运行时 XAML、Revit API 数据和 Owner/ExternalEvent 生命周期。
- **安装器设计：可支持 2021–2027。** 前提是正式安装包中含七套对应年份真实编译产物。

## 架构判断

### 做得较好的部分

1. Revit 2021–2027 采用同一源码、按年份 Configuration 独立编译，未使用跨年份 DLL 冒充兼容。
2. 模型写操作普遍使用 Transaction/TransactionGroup；大型非模态管理窗口通过 ExternalEvent 返回 Revit 主线程。
3. WPF 主题资源限定在 YangTools 根元素，不创建第二个 Application，不污染 Revit/ACC 全局资源。
4. AI 内置调用和外部 MCP 共享统一 RevitExecutionBroker；MCP 网关默认关闭、仅 loopback、动态端口和随机令牌。
5. 安装目标为用户级 Addins 目录，天然免管理员权限。

### 当前主要技术债

1. UI 仍以大型 code-behind 为主，四个文件超过 800 行，维护和回归风险较高。现阶段不建议为了形式重构全部 MVVM，只在真实问题出现时拆服务。
2. 项目历史编译曾有数百个 nullable 警告；它们不等于运行错误，但会降低新空引用问题的可见性。后续应按启动链、AI、项目管理三个区域逐步收敛。
3. 没有真正的 Revit 自动化 UI 测试。静态脚本只能捕获 XML、资源和事件绑定问题，不能证明构造函数读取真实 Document 数据时不会异常。
4. 2021–2023、2026–2027 的完整编译/启动证据不足；兼容结构正确，但发布状态不能写成已实机通过。

## 面板检查结果

静态脚本检查以下内容：

- 202 个文本文件严格 UTF-8 解码。
- 39 个 XAML/XML 可解析。
- 34 个 XAML 根节点都有匹配代码后置类。
- 所有 XAML 事件处理器在代码后置中存在。
- StaticResource/DynamicResource 未发现未定义键。
- 4 套主题资源键集合和资源类型一致。
- 所有 XAML 代码后置均通过 `ThemeHelper.InitializeWithTheme` 初始化。
- 源码未创建第二个 WPF Application，未写入 `Application.Current.Resources`。
- Ribbon 命令数量为 27。

结果：**错误 0，警告 0。**

### Revit 实机入口分类

- 24 个 Ribbon 入口会直接打开窗口或先显示配置窗口。
- `标注替换` 需要先选择标注后才打开窗口。
- `标高修改` 需要先选择图元后才打开窗口。
- `剖面(By Line)` 是直接拾取并执行的命令，没有 WPF 面板。

## 安装器设计

新增入口：`installer/YangTools安装器.cmd`。

功能：

- 自动检测 Revit 2021–2027。
- 显示每个年份的 Revit 检测、payload 可用、插件安装状态。
- 多选安装/更新、卸载。
- Revit 运行时拒绝修改文件。
- staging 复制、backup 回滚，降低更新中断导致插件目录损坏的风险。
- 卸载保留 `%APPDATA%\YangTools` 设置和 AI 历史。
- 不请求 UAC，不写注册表，不写 Program Files。

正式打包默认拒绝缺少年份产物的“伪全版本包”；调试时只有显式 `-AllowPartial` 才允许部分年份。

## 2021–2027 支持边界

| Revit | 目标框架 | 安装器 | 发布前要求 |
| --- | --- | --- | --- |
| 2021–2024 | .NET Framework 4.8 | 支持 | 各年份独立编译 |
| 2025–2026 | .NET 8 Windows | 支持 | 各年份独立编译 |
| 2027 | .NET 10 Windows | 支持 | .NET 10 SDK + 2027 API 独立编译 |

安装器本身只是复制对应 payload；它不会把一个 DLL 转换成其他年份兼容版本。

## Windows/Revit 最小验收顺序

1. 运行 `核验源码.cmd`。
2. 运行 `静态检查面板与编码.cmd`。
3. 编译 2024、2025；再编译 2021–2023、2026–2027。
4. 生成安装包，使用图形安装器安装 2024。
5. Revit 2024 打开测试项目，逐个点击 27 个 Ribbon 入口。窗口只需确认：可打开、中文无乱码、主题资源正常、关闭不崩溃。
6. 对非模态窗口重复点击，确认只激活现有实例。
7. 卸载 2024，确认 Addins 中 DLL/manifest 清理且个人设置保留。
8. Revit 2025、2027 做启动和核心窗口抽查。

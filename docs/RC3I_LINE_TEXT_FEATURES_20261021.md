# RC3I 线条和文字合并 — 静态开发候选（Revit 2021–2027）

本任务在 RC3H 完整源码上新增两条 Ribbon 命令，增强旧有 `文本合并`。其余 12 个钢筋测试入口维持已删除；GR01/MCP 未修改。未在 Windows 编译，未在 Revit 运行，禁止称 BUILD/GUI/Undo GO。

## 1. 合并直线（模型修改区）

- 对象限制：当前视图 **DetailCurve + GeometryCurve is Line**；不处理 ModelLine、弧线、样条、组内或固定元素。
- 端点连接容差：0.1 mm（仅填补建模舍入误差，绝不跨远距离跳段）；方向正反均可。线型 ID 一致才并组。
- 合并前必须同时检验端点相接、共线、最短曲线阈值、目标视图及只读状态；不能合并拐角、交叉、不相连或不同线样式。预览确认后单事务新建+删旧；任一步失败回滚；一次 Ctrl+Z 撤销。
- 原直线被标注引用时可能使标注失效：首个 2024/2025 测试项目重点验证。实际生产推荐先备份。

## 2. 双列文字合并（文本工具区）

- 选同一视图至少四个文本；根据视图的 `RightDirection/UpDirection` 识别行与两列，要求明显的水平间距。旋转文本、固定/编组、混合 TextNoteType 自动拒绝。
- **单个多行 TextNote**：每行将左列补空格至固定字符列宽再接右列。注意：英文字体如 Arial 是比例字体，空格**不能保证**精确右对齐；这是近似排版。
- **两个多行 TextNote**（推荐）：左右两列分别成为一个多行文本对象，沿原来两列的起始位置精确定位，段落行号一致；注意不同字体/大小可能仍需人工调整段距。
- 用户在对话框中选择方式；创建新文字后删旧，单事务+单次 Undo；模型/文本样式失败直接回滚。

## 3. 阅读顺序文本合并（已有文本合并按钮扩展）

- 新增 `ReadingOrder`：先根据视图上方向从高到低聚合行（行间距根据 TextNote 字高容差判断），再按视图右方向从左到右拼接。
- 原 TextNote 内部 `\r`、`\n`、TAB 和重复空格由 `CleanWhitespace` 可选清理。同行用单个空格；换行或自定义行分隔由现有选项决定。
- 保留原有选择顺序、单轴排序模式；合并前弹出可核对的文本预览；事务保留一个原文本、删除其余；单次 Undo。

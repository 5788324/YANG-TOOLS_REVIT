# YangTools 3.1.35 线性布置高程控制说明（2026-08-12）

## 目标

为“模型修改区 → 线性布置”增加显式高程控制：用户选择一个 Revit 标高，并输入起点、终点相对高程；首尾轮廓实例对应两个端点，中间实例按路线位置线性插值。

## UI

- 基准标高：从当前文档全部 `Level` 中选择。
- 起点高程（mm）：相对所选标高的偏移，可正可负。
- 终点高程（mm）：相对所选标高的偏移，可正可负。
- 界面以 `Level.ProjectElevation` 显示“标高项目高程”；若 `Level.Elevation` 与其不同，同时显示“显示高程”，用于识别共享坐标显示偏移。

## 高程公式

设：

- `L` = 所选 `Level.ProjectElevation`（Revit 内部英尺，始终相对项目原点）；
- `Hs` = 起点相对高程；
- `He` = 终点相对高程；
- `r` = 当前实例在实际首尾实例之间的路线位置比例，范围 0~1。

则：

`H(r) = Hs + (He - Hs) × r`

`WorldZ(r) = L + H(r)`

因此若标高项目高程为 +12000 mm、起点相对高程 -500 mm，起点世界高度是 +11500 mm。若该标高因共享坐标设置显示为另一数值，也不得把显示差值再次叠加进 XYZ。

## 首尾定义

- 第一个实际生成实例：`r=0`，精确使用起点高程。
- 最后一个实际生成实例：`r=1`，精确使用终点高程。
- 中间实例：按 `DistanceAlongPath` 线性插值。
- 固定间距且末端有余量、用户未勾选“终点补放”时，终点高程仍对应最后一个**实际生成**实例。
- 只有一个实例时无法同时满足两个高程；若二者不同，明确提示并使用起点高程。
- 开启“反转路线首尾”后，高程方向跟随反转后的有效路线。

## 放置与撤销

所有实例仍在一个 `Transaction` 内创建。每个实例通过 `FamilyPlacementHelper.CreateAtWorldPoint`：

1. 关联用户所选 Level；
2. 按计算后的世界 XYZ 创建；
3. Revit 再生后校验 `LevelId`；
4. 校正并再次验证 `LocationPoint`；
5. 任一异常触发事务回滚。

因此整批操作保持一次 `Ctrl+Z` 撤销。

## 2026-08-13 实机错误修正

用户报告：期望 Z 约 9000 mm、实际 Z 约 5500 mm、差约 3500 mm。该数值与 `Level.Elevation` 和 `Level.ProjectElevation` 的坐标基准差完全吻合。世界 XYZ 公式已从 `Level.Elevation + relative` 改为 `Level.ProjectElevation + relative`，并将此 3500 mm 差值加入自动回归。

# YangTools Ribbon 功能开发规范（强制）

适用范围：所有已存在和未来新增的正式 Ribbon 命令；临时插件箱中转为正式工具时同样适用。此文档是当前生效的 Ribbon UX 规则，不替代各功能业务/事务规范。

## 1. 名称与分区

1. `ButtonText` 必须是**中文为主、动作明确的短名称**，建议 2–5 个汉字，最多 6 个可见字符（含英文/数字按可见字符计）；只有行业缩写不可避免时使用 CAD 等短写。禁止 `（测试）`、版本号、`By Line`、`管理器` 等冗余后缀占 Ribbon 空间。
2. 名称必须区别相邻工具的目的，例如「直线合并」（连接）与「重叠清理」（有重叠）。不能为了缩短而夸大处理对象范围。
3. `PanelName` 必须从现有面板选取；新建面板须先审查按钮密度和导航；禁止同一工具多个 Ribbon 入口。
4. 移动面板不得改变 `IExternalCommand` 类型全名和 Revit AddInId，必须兼容旧 `ribbon_config.json` 显隐偏好，不覆盖用户设置。

## 2. 功能介绍与使用帮助

1. 每条 `[RibbonButton]` 必填：`tooltip`（一句话**说明做什么**）、`usage`（**使用步骤 + 适用对象/限制/风险**）。两者都必须是中文，禁止空字符串、废话或不被实际源码支持的成功承诺。
2. `tooltip` 展示在 Ribbon 简短提示；`usage` 写入 `PushButtonData.LongDescription`，需明确 **先选/后选、目标视图/对象类型、关键操作步骤和可能的删除/覆盖行为**。
3. 修改功能入口、选择逻辑、业务行为、风险或兼容性时，应在同一次改动中更新短名/描述/使用说明，以及 `docs/RIBBON_FEATURE_CATALOG_RC3J.md`；不允许文案与实际功能脱节。
4. 对危险操作，要在功能自身对话框提示具体目标、变更规模及确认路径；不能仅依赖 Ribbon 提示；静态文案不等于运行验收。

## 3. 图标规范

1. 必须遵守 `docs/ICON_DESIGN_GUIDE.md` 的线条风：32×32/16×16 透明 PNG，统一用 SVG 母版生成，主色 `#355D7A`、强调色 `#6E9FC4`，不用渐变/照片/文字。
2. **不同正式功能禁止复用同一图标文件路径，且应检查实际视觉语义区别。** 同尺寸跨按钮 PNG 不能重复；16/32 必须是同一母版。
3. 图标要表现功能对象和关键动作，不能只改变同一图标的文件名；默认从 `tools/Generate-RibbonIcons.py` 生成，修改图标必须同时维护生成器映射。
4. 不允许使用不存在、丢失大小图的资产，不让 Ribbon 静默降级为空图标；不得引入未引用 PNG。

## 4. 每个功能开发的硬门禁

- [ ] 简短且唯一的按钮名，放入正确面板（检查按钮总数/面板数）。
- [ ] 正确的 Tooltip，LongDescription 含真实使用步骤、输入条件、风险边界。
- [ ] 32px 和 16px 唯一、存在、透明通道正确的图标；检查 16px 清晰度和与相邻按钮的辨识度。
- [ ] `tools/Test-RibbonUxContract.py` 静态门禁通过；图标生成器重跑不会删除已用资产。
- [ ] 对涉及修改模型的命令，独立验证预览/事务/回滚/读回/一次 Undo；若删除重建 ElementId，额外检查尺寸标注/约束引用。
- [ ] Windows 六版本隔离编译后，才能声明新候选 BUILD GO；Revit GUI/F2 与发布状态必须独立验收，2023 生产环境不可触碰。

## 5. 版本边界

本规范在 RC3J Ribbon UX 候选上新增；仅修改 UI 元数据、图标和文档，不证明已有几何缺陷已修复。部署、回滚、生产环境保护仍按项目交接约定执行。

## 6. 几何整理工具额外门禁（2026-10-22）

1. 端点连接与正长度重叠是不同操作；严禁使用单一宽松共线条件把相交、分叉或重叠误归为一类。容差同时检查整个线段的端点到参考直线的垂距；多对象聚类须防止容差链式漂移。
2. 遇到带尺寸标注引用、依赖元素、约束、组内或锁定对象，按当前已知 API 检查并保守跳过；不得把“原 ElementId 被保留”当成标注永远安全的保证。删除返回的额外受影响 ID 必须触发整个事务回滚。
3. 每个功能都要支持符合原工作流的先选/后选，并在预览里说明操作数量、跳过原因、引用风险；修改后读回目标几何，统一一次 Undo。
4. 必须分别用非生产测试模型验证：端点正接、0.05 mm 误差、0.11 mm 误差、轻微倾斜、交叉、部分重叠、完全重复、包含、链式偏移、T 分叉、闭环、异线型、尺寸标注及单次 Ctrl+Z。
5. “隐藏边界”优先按 Revit 系统内建类别识别有效线型，禁止硬编码仅英文名称；无唯一合法匹配时不得修改，也不能把其他独立线条误报为填充边界。
6. 静态模拟测试不是 Revit 实机证据；Gemini 等执行器需回传原始命令、日志、哈希、元素 ID/几何读回与完整可核验操作记录。禁止凭文字宣布 Runtime GO。

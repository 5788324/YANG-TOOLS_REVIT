# YangTools 3.1.35 — 中文检查与清理升级（2026-08-07）

## 目标

将原来的四块只读 ListBox 中文检查窗口升级为分类表格工具，便于在大型项目中按资源类型逐组检查、定位、重命名和清理中文内容。

## UI

- 左侧：分类导航与数量。
- 右侧：当前分类 DataGrid。
- 支持搜索、全选、全不选、反选。
- 每行独立复选框；批量操作只针对当前分类/当前筛选结果。
- 双击“名称 / 内容”列修改支持写入的对象。
- 表格明确显示 Element ID、可改名、可删除、风险级别。

## 写操作语义

### 重命名 / 修改

支持的行根据对象类型执行对应 API：
- `Element.Name`
- `TextNote.Text`
- 字符串 `Parameter.Set(string)`
- `WorksetTable.RenameWorkset`
- `ViewSheet.SheetNumber`
- `ScheduleField.ColumnHeading`
- `SpatialElement.Number`
- `AssemblyInstance.AssemblyTypeName`
- `Revision.Description / RevisionDate / IssuedBy / IssuedTo`

不支持直接改名的参数定义、Revit 内置对象等会显示“可改名 = 否”。写入失败时事务回滚并显示错误，不静默吞掉。

### 删除 / 清空

- 实体对象：使用 `Document.Delete(ElementId)`。
- 字符串参数文本值：“删除”表示清空字符串，不删除宿主元素。
- 参数名称、工作集等没有安全删除语义的项目禁止删除。
- 删除前在回滚事务中执行级联影响预检并统计 Revit 返回的受影响 ElementId。
- 高风险对象必须二次确认。
- 批量实际处理使用一个主 `Transaction` + 每项 `SubTransaction`；单项失败只回滚该项，整个成功批次可一次 Ctrl+Z 撤销。

## 安全边界

1. 不使用名称查找来确定参数写入目标；字符串参数按宿主 ElementId + Parameter.Id 重新定位。
2. 不扫描链接文档内部或族文件内部内容。
3. 不把 `AsValueString()` 的本地化数值显示当成真实文本。
4. 每个分类最多保留 10000 条结果，防止异常项目占用过多 UI 内存。
5. 族、类型、标高、图纸、项目参数、链接等删除标为高风险，必须依赖 Revit 级联预检与确认。

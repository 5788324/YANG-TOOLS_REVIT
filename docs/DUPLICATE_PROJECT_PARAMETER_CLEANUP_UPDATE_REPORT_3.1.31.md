# YangTools 3.1.31 更新报告

## 已完成

- 新增全选、全不选、反选。
- 新增“测试：最多 10 个来源参数”。
- 新增已选组数/来源参数数实时统计。
- 删除由逐项执行改为 25 个一批。
- 异常批次自动回滚并二分定位。
- 保留单项级联删除保护。
- 新增删除性能统计。
- 新增参数清理链路模拟脚本。

## 性能判断

用户项目扫描 2750 个项目参数、606 个重复组仅需约 55ms，扫描不是瓶颈。旧删除模式可能对上千来源参数执行上千次 `Document.Delete` 与子事务提交。新模式在全部安全时，606 个候选只需约 25 个初始批次调用。

## 验证状态

当前环境完成：

- XAML、资源、事件处理器、UTF-8 静态检查；
- 选择逻辑模拟；
- 自适应批量删除模拟；
- 单次遍历和原始值复制源码契约检查。

当前环境没有 Windows/Revit，真实编译和 Revit 删除事务必须按 3.1.31 验收单完成。
